# 공유 페이지 모바일 레이아웃 개선

## 목표

`/invites/phishing-challenge/demo` 공유 페이지가 iPhone Safari처럼 실제 가용 높이가 짧은 환경에서도 안정적으로 보이게 한다. 펭귄 캐릭터와 `가족 · 친구랑 챌린지 시작!` 버튼이 겹치지 않고, 버튼은 항상 캐릭터 아래에 배치한다.

## 현재 문제

- 캐릭터 이미지와 CTA가 서로 다른 절대 위치를 사용한다.
- CTA는 화면 바닥을 기준으로, 캐릭터는 화면 위를 기준으로 배치되어 기기 높이에 따라 서로 겹친다.
- 고정 하단 탭과 Safari 브라우저 UI가 실제 콘텐츠 높이를 줄이면 문제가 더 두드러진다.

## 선택한 설계

- 상단 제목과 설명의 현재 디자인은 유지한다.
- 기존 Figma 캐릭터와 배경 장식 자산을 그대로 사용한다.
- 캐릭터를 반응형 비율을 가진 일반 문서 흐름의 영역에 배치한다.
- CTA를 캐릭터 영역 바로 다음 요소로 배치해 위치 관계를 구조적으로 보장한다.
- CTA 아래에는 고정 하단 탭에 가려지지 않는 여백을 둔다.
- 콘텐츠가 짧은 화면에 모두 들어가지 않으면 공유 페이지 본문만 자연스럽게 스크롤되도록 한다.
- 390px 기준 현재 시각 비율을 유지하고, 320px 이상 모바일 너비에서 가로 스크롤이 발생하지 않게 한다.

## 영향 범위

- `ShareLandingPage`의 레이아웃 클래스와 구조만 변경한다.
- 하단 탭, 헤더, 라우팅, CTA 동작과 텍스트는 변경하지 않는다.
- 다른 챌린지 및 골든타임 화면에는 영향을 주지 않는다.

## 검증

- 회귀 테스트로 공유 페이지의 CTA가 캐릭터 영역 다음에 오는 구조를 확인한다.
- 390×844과 첨부된 iPhone 화면 비율에 가까운 뷰포트에서 시각 비교한다.
- 버튼과 캐릭터가 겹치지 않고, 버튼과 하단 탭 사이 여백이 유지되는지 확인한다.
- 전체 테스트, 타입 검사, 프로덕션 빌드를 실행한다.
